# Java

### Java vs CPP
- Java is platform independent, CPP is platform dependant.
- Multiple inheritence isnt allowed in Java in CPP its allowed.
- Pointers are not there in Java but in CPP the pointers are allowed.

### Java under the hood
- Java compiles into class files, and class files are converted by JVM to byte-code depending on the platform which it runs on
- Hence Java is compile once run anywhere.

### JDK vs JRE vs JVM
- JVM is a Java virtual machine which takes in class files and converts it to appropriate byte-code depending on the platform.
- JRE is runtime environment which holds libraries necessary to support java code, it holds JVM within it
- JDK is development kit which also holds software like javac to compile the code, it has JRE within it to support application development. JDK is group of softwares
