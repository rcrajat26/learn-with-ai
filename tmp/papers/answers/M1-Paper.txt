Q2. Walk through what happens internally on map.put(key, value) for a HashMap: how the bucket is chosen, what happens on a collision, and what happens when the map gets "too full."
- The hashcode of key is computed, based on the hash code result a bucket is chosen and a node with key-value is added.
- Next time if a key's hashcode turns out to be same a collision is said to have occurred and this element is added as next node at the same bucket not the bucket contains a linked list of 2 elements.
- when map gets too full redistribution happens to make more buckets 1.5x the current size and elements are redistributed, we cant say for sure that 2 elements that were on the list previously also remain together it depends if the remainder comes out to be same.
