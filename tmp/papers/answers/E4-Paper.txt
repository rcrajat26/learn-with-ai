    .filter(s -> s.startsWith("a"))
    .distinct()
    .count();

- filter removes bob, cara hence anna and anna (lowercased) remains
- finally distinct gives unique element, and finally count will be 1.

Q6. What is garbage collection? Which objects are eligible? Does System.gc() guarantee a collection?
- GC is a process where the dangling objects are cleared off the memory.
- Objects which are not referenced by other objects or in static memory by a member reference are considered for GCing.
- No calling System.gc() doesnt guarantee a GC. It gives a hint to JVM that its time to run a GC.

Q13. For GET /users/42/orders?status=SHIPPED&page=2, identify the path parameter and the query parameters. When does data belong in the path vs the query string vs the request body?
- path param userID - 43, query param - status,page
- When we are accessing a resource based on its primary identification is being address we use path param
- When we are filtering a resource based on other member values we lean on query param
- When we are creating a resource we pass the details that are associated with that resource in the request body

- If a message is not delivered it could lead the state of application in undesired state for given user(s), hence we must check and replay the messages in DLW after ascertaining why it was not delivered

Q16. In-process cache (e.g., a HashMap/Caffeine inside your service) vs external cache (e.g., Redis): one advantage of each. What goes wrong with in-process caches when you run 4 instances of the service?
- In process cache is fast unlike external cache which needs to be fetched from external system.
- External cache is big and dedicated for caching work hence delivers greater flexibility
- When multiple instances of the same service are running and maintaining a cache which gets updated (not just read) then inconsistency can arise as each instance maintains its own version of cache
