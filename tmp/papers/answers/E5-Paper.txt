- Arrays occur in sequential memory blocks while LL members can be kept non-sequentially.
- due to bigger memory in latest hardwares lesser re-organising of array is needed hence it thrives better because of index polling.

Section 6 — Networking & OS
Q11. When your browser requests https://example.com, name the protocol layers/steps involved in order, from typing the URL to receiving HTML (high-level — four or five steps).
- First DNS kicks in and com as TLD is figured out.
- From the TLD server we figure out appropriate DNS server and using that we get A record which gives the appropriate IP address.
- We hit the application server with that IP on 443 port over HTTPS protocol
- The app server hits a required endpoint and gets the html file and gets rendered by client which requested the endpoint.

- Such requests must only be sent on https as they are secure channel and compromising JWT gives access to malicious user
