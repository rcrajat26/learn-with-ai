Section 2 — Java Core
Q3. What are the three distinct uses of the final keyword, and what does each prevent? Does a final List field mean the list can't change?
- final variable cant be assigned with a different value (if holding a reference, cant change its reference but value stored in the reference can be changed)
- final method cant be overridden in the child class
- final class cant be inherited (hence abstract class or interface cant be final)
- a final list means the assigned list cant be changed to a different list but the list can be operated upon add/remove/update are allowed.
--------------
Q4. Primitives vs wrapper classes (int vs Integer): name two differences, and one place where only the wrapper works.
- primitive is a simple value not a class
- hence primitive doesn't support any methods.
- While wrapper class is a wrapper around the particular primitive provides methods to operate on the value.
- In the collections we can only use wrapper class and not primitive types

Section 7 — API & Web Security
Q13. Authentication vs authorization — define each, and give the HTTP status code conventionally used when each one fails.
- Authentication is whether the user has right credentials - on failure we reply 401. Authorization is whether the user has role to access the requested resource - on failure we reply 403.
--------------
Q14. What does it mean for an operation to be idempotent? Which HTTP methods are idempotent by contract, and why does it matter for retries?
- An Idempotent operation is the one which upon multiple tries won't change the state of resource
- by contract GET and DELETE are idempotent
- a non-idempotent operation upon retrying can create duplicate copies of the resource or subresource

Q15. In messaging, what do the terms producer, consumer, and broker mean? What happens to messages if all consumers are temporarily down?

Q16. Cache hit vs cache miss. Your cache shows a 15% hit ratio — is the cache helping? What would you check?
- Cache hit is when we have the requested key's data in the cache, cache miss is when we have not cached the data for requested key
- A low cache hit ratio means cache isn't helping, we would check the cache to see if have enough space
