## Attempt 2
- For missing k value I'd return s+1
- The time complexity of code is O(N) and space complexity is O(1)
- New code:
- ```
  class Solution {
    public int removeDuplicates(int[] nums) {
        if (nums.length == 0) return 0;
        if (nums.length == 1) return 1;
        int c=1,s=0;
        while(c<nums.length) {
            if (nums[c]>nums[c-1]) {
                nums[s+1]=nums[c];
                s++;
            }
            c++;
        }
        return s+1;
    }
  }
  ```
